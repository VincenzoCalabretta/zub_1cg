# External reference documents

Vendor PDFs and their generated text/table extractions are intentionally not
distributed with this repository. They remain copyrighted by Arm,
AMD/Xilinx, Avnet/Tria, or their suppliers and are not covered by this
project's MIT license.

Obtain documents directly from their publishers:

- Arm Cortex-R5 TRM, DDI 0460D:
  <https://developer.arm.com/documentation/ddi0460/d/>
- Arm Cortex-A53 TRM, DDI 0500J:
  <https://developer.arm.com/documentation/ddi0500/j/>
- AMD Zynq UltraScale+ Device TRM, UG1085:
  <https://docs.amd.com/r/en-US/ug1085-zynq-ultrascale-trm>
- ZUBoard 1CG hardware guide, getting-started guide, schematic, and BOM:
  <https://www.tria-technologies.com/product/zuboard-1cg/>

Authorized developers may keep local copies in this directory. Git ignores
those copies and all generated output. Public documentation should link to
the publisher rather than reproduce or mirror the source material.
